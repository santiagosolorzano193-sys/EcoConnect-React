# EcoConnect - React SPA

Aplicación de página única (SPA) desarrollada con React y Vite para la iniciativa de reciclaje inteligente EcoConnect[cite: 14].

## Descripción del Proyecto
Migración de la landing page estática a una aplicación modular de React utilizando componentes reutilizables, JSX y enrutamiento con React Router[cite: 14].

## Tecnologías Utilizadas
* **React.js & Vite:** Entorno de desarrollo rápido y estructuración modular por componentes.
* **JavaScript (ES6+):** Lógica interactiva de la aplicación.
* **HTML5 / CSS3:** Estilos responsivos y modernos.
* **Git y GitHub:** Control de versiones y alojamiento de código.
