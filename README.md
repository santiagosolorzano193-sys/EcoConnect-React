# EcoConnect - React SPA

Aplicación de página única (SPA) desarrollada con React y Vite para la iniciativa de reciclaje inteligente EcoConnect.

## Descripción del Proyecto
Migración de la landing page estática a una aplicación modular de React utilizando componentes reutilizables, JSX y enrutamiento con React Router.

## Requisitos Previos
- Node.js instalado en tu equipo.

## Instrucciones de Instalación y Ejecución

1. Clona o descarga este repositorio.
2. Abre la terminal en la carpeta principal del proyecto.
3. Instala las dependencias ejecutando:
